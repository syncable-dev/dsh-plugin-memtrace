# Glossary

| Term | Meaning |
| --- | --- |
| Bundle | npm package whose `dsh.bundle.patch` inserts Cordis rows into a profile |
| Profile | Named DSH composition under `$DSH_HOME/profiles/` |
| Memtrace | Local code-intelligence graph and MCP server |
| Skill | Agent Skills `SKILL.md` workflow registered on `ctx.skills` |
| `mcp__memtrace__*` | Public tool names the official DSH MCP client assigns |
